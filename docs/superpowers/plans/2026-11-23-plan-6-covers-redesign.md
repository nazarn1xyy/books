# План 6: редизайн «обложки в центре»

> Выполнять inline (superpowers:executing-plans), без субагентов. Код искать через **graphify**
> (`graphify query "<имена>" --budget 1500`, `graphify explain`, `graphify path`); grep — только для CSS-классов.
> Для визуальных решений — skill `frontend-design:frontend-design`.

**Goal:** Ощутимо сменить вид в духе Apple Books: обложки книг — главный визуальный элемент, цветовые акценты
берутся из обложек, тёмная база сохраняется, светлая тема продолжает работать (токены из Плана 4).

**Решения (утверждены пользователем: направление «Обложки в центре»):**

1. **«Мои книги» → сетка обложек** вместо списка карточек: `BookGrid` (2 колонки телефон → 6 десктоп), под обложкой
   название (2 строки) и автор (1 строка, `text-subtle`), тонкая полоска прогресса прямо по нижнему краю обложки.
   Серии — одна обложка «стопкой» (2–3 смещённые тени/подложки) с бейджем количества; клик раскрывает серию.
   Удаление — через контекстное меню (долгое нажатие / кнопка «…» при наведении), свайп на сетке убрать.
   Переключатель «Сетка / Список» в шапке (сохраняется в localStorage), список — текущий вид.
2. **Главная → hero «Продолжить чтение»:** большая карточка последней книги: обложка слева (крупно), справа название,
   автор, прогресс в %, кнопка «Продолжить»; фон карточки — размытая и затемнённая копия обложки
   (`<img>` с `blur-3xl scale-125 opacity-40` под градиентом в `bg-app`). Ниже — горизонтальная лента остальных
   начатых книг (scroll-snap) и сетка рекомендаций.
3. **Цвет из обложки:** `shared/lib/coverColor.ts` — `extractDominantColor(img): Promise<string>` через `<canvas>` 24×36,
   усреднение с отбрасыванием почти чёрных/белых пикселей, кеш в `Map` + localStorage по URL. Применять как
   CSS-переменную `--cover-accent` (свечение/тень вокруг hero, цвет прогресса на hero). Обложки через наш прокси
   same-origin, поэтому canvas не «грязнится»; для `data:`-обложек тоже ок. Ошибка → нейтральный цвет.
   Unit-тест на функцию усреднения (вынести чистую `averageColor(pixels: Uint8ClampedArray)`).
4. **Обложки:** единый компонент `BookCover` (`entities/book/ui`): `aspect-[2/3]`, `rounded-[6px]` слева чуть меньше
   («корешок»: лёгкий вертикальный градиент-блик 6px у левого края), тень `shadow-[0_8px_24px_rgb(0_0_0/0.35)]`,
   hover на десктопе — `-translate-y-1` + усиление тени. Заглушка без обложки — `BookCoverFallback` в том же каркасе.
5. **Типографика:** заголовки страниц 34px/700 с `tracking-tight` (как iOS Large Title), секции 20px/600;
   один шрифт интерфейса (системный стек `-apple-system, "SF Pro Text", Inter, system-ui`), без новых веб-шрифтов.
6. **Баг:** HTML-сущности в названиях (`&laquo;`, `&raquo;`, `&amp;`, `&#NNN;`) — декодировать при парсинге OPDS и FB2
   (`shared/catalog/decodeEntities.ts` через `DOMParser`/`textarea` нельзя в воркере → своя таблица именованных
   сущностей + числовые `&#\d+;`/`&#x[0-9a-f]+;`), с unit-тестом; и при показе уже сохранённых названий
   (применить в маппере метаданных книги), чтобы починить существующие записи.
